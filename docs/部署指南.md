# Recall AI 错题本：免费部署指南

推荐方案：**Vercel（免费托管 Next.js）+ Supabase（免费云数据库）**。全程不需要信用卡，适合课程作业演示。

代码已经内置 Supabase 云端持久化：部署后新增/修改的错题会保存到云端，不会因为服务器重启而丢失。不配置 Supabase 时仍会在本地使用 `data/recall-db.json`，方便开发。

## 准备

- GitHub 账号（仓库已经推到 GitHub）
- Supabase 账号（邮箱注册即可）
- Vercel 账号（直接用 GitHub 登录）
- 本地 `recall-app/.env.local` 里的 DeepSeek / OCR.space 密钥（部署时要复制到 Vercel）

## 1. 创建 Supabase 项目

1. 打开 [supabase.com](https://supabase.com)，注册并登录。
2. 点 **New project**。
3. 项目名称随意，例如 `recall-ai`；设置数据库密码并记下来；Region 建议选 **Singapore（东南亚）** 或 **Tokyo（日本）**，国内访问相对快。
4. 等几分钟让项目创建完成。

## 2. 创建云端数据表

1. 左侧菜单进入 **SQL Editor**。
2. 新建查询，粘贴仓库中 `supabase/schema.sql` 的内容。
3. 点 **Run**，看到成功提示即可。这会创建一张 `app_state` 表，用来保存整个错题本数据。

## 3. 关闭邮箱确认

默认情况下 Supabase 注册后会要求先点邮件确认链接，课程演示会很麻烦。

1. 左侧菜单进入 **Authentication** -> **Sign In / Providers**。
2. 找到 **Email**，点 **Edit**。
3. 取消勾选 **Confirm email**，保存。

## 4. 创建演示账号

让登录页的“使用演示账号进入”按钮可以直接使用：

1. 进入 **Authentication** -> **Users** -> **Add user**。
2. Email 填 `demo@recall.app`，密码填 `recall123`。
3. 确保 **Auto Confirm User** 开启（不同版本界面可能叫法不同）。
4. 点 **Add user**。

## 5. 获取 Supabase 密钥

1. 左侧菜单进入 **Project Settings** -> **API**。
2. 复制三个值：**Project URL**、**anon public**、**service_role**。
3. `service_role` 是敏感密钥，只能填到 Vercel 服务端环境变量里，不要贴到公开代码或网页中。

## 6. 部署到 Vercel

1. 打开 [vercel.com](https://vercel.com)，用 GitHub 账号登录。
2. **Add New** -> **Project**，找到 `recall-ai-wrong-book` 仓库，点 **Import**。
3. **Root Directory** 选择 `recall-app`（项目在仓库子目录里）。
4. Framework Preset 会自动识别 Next.js，Build Command 和 Output 设置保持默认。
5. 在 **Environment Variables** 中添加：

   | 变量名 | 值来源 |
   | --- | --- |
   | `NEXT_PUBLIC_SUPABASE_URL` | Supabase Project URL |
   | `NEXT_PUBLIC_SUPABASE_ANON_KEY` | Supabase anon public |
   | `SUPABASE_SERVICE_ROLE_KEY` | Supabase service_role |
   | `DEEPSEEK_API_KEY` | 本地 `.env.local` |
   | `DEEPSEEK_BASE_URL` | `https://api.deepseek.com` |
   | `DEEPSEEK_MODEL` | `deepseek-chat` |
   | `OCR_SPACE_API_KEY` | 本地 `.env.local` |

6. 点 **Deploy**，等几分钟。

## 7. 验收

1. 打开 Vercel 生成的 `https://xxx.vercel.app`。
2. 点“使用演示账号进入”，或者先注册再登录。
3. 测试：录入错题（未配置 OCR 时会走内置演示识别）、错题列表、看板、复习、计划、AI 对话。
4. 新增/修改数据后刷新页面，数据仍然在，说明云端持久化已生效。

## 常见问题

- **打开页面 500 或 API 报错**：检查 Supabase SQL Editor 是否执行过 `schema.sql`，以及 Vercel 三个 Supabase 变量是否填写正确。
- **登录提示邮箱未确认**：检查 Supabase Authentication 里是否关闭了 Confirm email，或演示账号是否开启了 Auto Confirm。
- **刷新后数据丢失**：确认 `SUPABASE_SERVICE_ROLE_KEY` 已配置。线上必须配置 Supabase；不配置时仍使用本地 JSON，但 Vercel 临时磁盘不会保留数据。
- **Supabase 免费项目连续 7 天无活动会暂停**：演示前登录一下 Supabase Dashboard 即可自动恢复。
- **Vercel 页面偶尔打不开**：国内网络访问国外服务可能不稳定，多刷新几次；正式演示前提前打开页面。

## 备用方案：Render 免费版

如果 Vercel 始终无法访问，也可以使用 [render.com](https://render.com) 免费 Web Service：

1. 同样导入 GitHub 仓库，Root Directory 选 `recall-app`。
2. Environment 选 Node；Build Command 填 `npm install && npm run build`；Start Command 填 `npm run start`。
3. 添加和 Vercel 相同的环境变量。
4. 免费实例闲置 15 分钟会休眠，首次打开可能需要等 30-60 秒。
