## 执行建议

- 未配置外部 API 时，系统自动使用 Demo Provider，应先跑通完整流程。
- 配置 `DEEPSEEK_API_KEY` 与 `OCR_SPACE_API_KEY` 后，重点回归识别准确率、超时重试和额度展示。
- 移动端使用 320px 视口执行响应式用例，桌面端使用 1200px+ 视口。
- 每次发布前执行 `npm run build`，并至少跑一遍 S1-TC-01、S2-TC-05、S3-TC-05、S5-TC-04、S5-TC-16。

## 测试结论

测试通过标准：所有 P0 用例通过，P1 用例无阻断性缺陷。当前实现已完成构建验证，核心链路可在本地 Demo 模式运行。
